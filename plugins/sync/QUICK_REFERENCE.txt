🎮 SPIELER-BEFEHLE (mit BedrockBridge Prefix)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HAUPTBEFEHLE:
!sync                           Öffne das Haupt-Menü
!sync transfer main             Transferiere zur Hauptwelt
!sync transfer farming          Transferiere zur Farmingwelt
!sync restore                   Stelle dein Inventar wieder her
!sync stats                      Zeige deine Transferstatistiken
!sync help                       Zeige die Hilfe

SCHNELL-BEFEHLE (Alias):
!transfer main                  Schnell-Transfer zur Hauptwelt
!transfer farming               Schnell-Transfer zur Farmingwelt

HINWEIS: Der ! ist der Standard-Prefix
Dein Server kann einen anderen Prefix verwenden (z.B. . oder $)
Nutze !help um ALLE Befehle zu sehen

Server-Namen ändern:
  Datei: crossServerSync.js
  Zeile: ~18-28
  Ändern:
    mainServer: { name: "DEIN_NAME" }
    farmingServer: { name: "DEIN_NAME" }

Transfer-Cooldown (in Sekunden):
  Datei: crossServerSync.js
  Zeile: ~48
  Ändern: transferCooldown: 300
  (300 = 5 Min, 1800 = 30 Min, 60 = 1 Min)

Whitelist aktivieren:
  Datei: crossServerSync.js
  Zeile: ~47
  Ändern: whitelist: ["PlayerName1", "PlayerName2"]

Discord deaktivieren:
  Datei: crossServerSync.js
  Zeile: ~47
  Ändern: discordLogging: false

Das Plugin erstellt automatisch 4 Datenbank-Tabellen:

1. crossServerSync_players
   Speichert: Spieler-Profile, Statistiken, Ban-Status

2. crossServerSync_inventory
   Speichert: Inventar-Backups, Items, Verzauberungen

3. crossServerSync_transfers
   Speichert: Transfer-Verlauf, Zeitstempel, Server-Info

4. crossServerSync_logs
   Speichert: System-Events, Fehler, Audit-Trail

🚀 WIE ES FUNKTIONIERT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Spieler gibt ein:           /sync
2. Wählt einen Ziel-Server:   🏠 Hauptwelt oder 🌾 Farmingwelt
3. Bestätigt den Transfer:    "JA" eingeben
4. Inventar wird gespeichert: System speichert alle Items
5. Spieler transferiert:      (im echten Setup würde Spawn hier happen)
6. Inventar wird geladen:     Alle Items werden wiederhergestellt
7. Benachrichtigung:          Discord & Chat-Nachricht erhalten

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: /sync Befehl nicht erkannt
→ Lösung: Server neu starten oder den import überprüfen

Problem: Inventar wird nicht wiederhergestellt
→ Lösung: /sync restore manuell nutzen oder Spieler umbenennen prüfen

Problem: Cooldown zu kurz
→ Lösung: transferCooldown im Code erhöhen (1800 = 30 Min)

Problem: Nur bestimmte Spieler dürfen
→ Lösung: Whitelist aktivieren und Spieler-Namen eintragen

Problem: Discord-Nachrichten fehlen
→ Lösung: discordLogging: false setzen oder Discord-Verbindung prüfen
