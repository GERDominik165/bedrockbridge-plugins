📊 NETZWERK-CACHE MECHANISMUS
──────────────────────────────

Caching-Strategie:

1. SAVE: Speichern in externe DB
   ├─ HTTP POST zu /api/inventory/save
   ├─ Speichere in lokalem networkCache
   ├─ Speichere lastSyncTime
   └─ Fallback: Ignoriere Fehler, continue

2. LOAD: Laden aus externe DB
   ├─ Prüfe networkCache (<5 Min)
   │  ├─ JA: Nutze lokale Kopie (1-2ms)
   │  └─ NEIN: HTTP GET zu /api/inventory/load
   ├─ Validiere Checksumme
   ├─ Speichere in networkCache
   └─ Fallback: Nutze alte Methode

3. CACHE-HIT:
   └─ Daten <5 Min alt → Nutze lokal (SCHNELL!)

4. CACHE-MISS:
   └─ Daten älter → Hole von externe DB

⚡ ERROR HANDLING & FALLBACK
────────────────────────────

Wenn Netzwerk-Fehler auftritt:

1. Netzwerk ausfällt
   ├─ HTTP-Fehler wird geworfen
   └─ Catch-Block handhabt es

2. Fallback-Kette:
   ├─ 1. Versuche externe DB
   ├─ 2. Wenn Fehler: Nutze networkCache (if <5 Min)
   ├─ 3. Wenn kein Cache: Nutze ExternalInventoryDatabase (lokal)
   └─ 4. Wenn alles fehl: Nutze alte lokale DB (getLatestInventory)

3. Spieler sieht:
   └─ KEINE UNTERSCHIED - Daten werden normal geladen/gespeichert!

4. Admin sieht in Logs:
   └─ Welche Methode verwendet wurde

Beispiel Log-Ausgabe:
  ✅ Externe DB (HTTP): Inventar gespeichert
  oder
  ✅ Cache-Hit: Nutze lokale Kopie
  oder
  ⚠️ Externe DB Netzwerk-Fehler: ... - Fallback zur lokalen DB

🛠️ MINIMAL EXTERNAL DB SERVER
─────────────────────────────

Node.js Express Server:

const express = require('express');
const app = express();
const inventories = {};

// Auth Middleware
app.use((req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (token !== process.env.EXTERNAL_DB_TOKEN) return res.status(401).json({error: "Unauthorized"});
  next();
});

// Health
app.get('/api/health', (req, res) => {
  res.json({healthy: true, status: "operational"});
});

// Save
app.post('/api/inventory/save', (req, res) => {
  inventories[req.body.playerName] = req.body.data;
  res.json({success: true});
});

// Load
app.get('/api/inventory/load', (req, res) => {
  const data = inventories[req.query.playerName];
  res.json({data: data || null});
});

app.listen(3000);
