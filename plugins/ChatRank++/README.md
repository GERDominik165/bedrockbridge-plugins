# ChatRank++ BedrockBridge Plugin

Version 2.0.0

## Description
Complete chat ranking and management system for BedrockBridge Minecraft servers.

## Features
- Advanced rank management with priority system
- Complete chat formatting with colors and effects
- Player muting and moderation tools
- Clan/team system with tags
- Custom display names
- Discord integration
- Statistics tracking
- Word filtering
- Permission system
- Comprehensive logging
- Admin UI dashboard

## Installation
1. Copy the ChatRank++ folder to your BedrockBridge plugins directory
2. Restart your server
3. Configure settings in-game or via config files

## Commands
See documentation for full command list. Key commands:
- `/rank` - Rank management
- `/mute` - Player muting
- `/clan` - Clan management
- `/chatrank` - Admin commands

## Permissions
- `chatrank.admin` - Full admin access
- `chatrank.moderate` - Moderation tools
- `chatrank.vip` - VIP features
- `chatrank.premium` - Premium features
