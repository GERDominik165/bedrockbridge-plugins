📋 WHAT IS THIS?
═════════════════════════════════════════════════════════════════════════════

This is a comprehensive Bedrock Bridge plugin that integrates with MCProfile.io
to retrieve player profile information. Profiles are displayed ONLY to admins
with the "admin" tag when they join the server.

Features Include:
  ✓ MCProfile.io API Integration (XUID, Floodgate, Java UUID)
  ✓ Admin-Only Profile Visibility
  ✓ Intelligent Caching (LRU with statistics)
  ✓ Event Handling (player join/leave)
  ✓ Admin Commands (4 custom commands)
  ✓ Network Management (connection pooling, retry logic)
  ✓ UI System (notifications, forms)
  ✓ Logging System (5 log levels)
  ✓ Configuration Management (multiple profiles)
  ✓ Testing Utilities (Python scripts)

⚙️ COMMANDS
═════════════════════════════════════════════════════════════════════════════

As Admin:

/mcprofile <identifier>        Query player profile
  Examples: /mcprofile 25332248730d7792
           /mcprofile cb7a4c0c-a7cd-4846-8bdf-477de8f5f3ee
           /mcprofile kobenetwork

/mcprofile-info                Show plugin version & status

/mcprofile-cache stats         Show cache statistics

/mcprofile-cache clear         Clear all cached profiles

/mcprofile-reload              Reload configuration

Regular:

/tag @s add admin              Add admin tag (needs operator)

❓ COMMON QUESTIONS
═════════════════════════════════════════════════════════════════════════════

Q: Can everyone see player profiles?
A: NO! Only admins with the "admin" tag see profiles.

Q: What if a player isn't linked?
A: The API returns bedrock profile only, no Java info.

Q: How long are profiles cached?
A: By default 1 hour (configurable).

Q: Does it cost anything?
A: NO! MCProfile.io API is free for public lookups.

Q: What Minecraft versions does it support?
A: Bedrock Edition 1.19.0+ with Bedrock Bridge.

Q: How do I add the admin tag?
A: In-game as operator: /tag @s add admin

Q: Can I customize admin tags?
A: YES! Edit config/settings.json: admin.tags

Q: What if API is down?
A: Plugin handles gracefully with error messages.

Q: Can I test without a live server?
A: YES! Run: python3 scripts/mcprofile-api-tester.py
