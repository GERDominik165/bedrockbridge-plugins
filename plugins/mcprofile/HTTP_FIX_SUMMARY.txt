BEDROCK HTTP CLIENT API:
═══════════════════════════════════════════════════════════════════════════════

HttpRequest Class:
  new HttpRequest(url)                    Create request
  request.setMethod(HttpRequestMethod.Get)    Set GET method
  request.addHeader(key, value)           Add header
  request.setTimeout(seconds)             Set timeout
  request.setBody(body)                   Set POST body

HttpRequestMethod Enum:
  Get     → GET request
  Post    → POST request
  Put     → PUT request
  Delete  → DELETE request
  Head    → HEAD request

http Object:
  http.request(request)                   Make request (returns Promise)
  http.get(url)                          Quick GET request

HttpResponse:
  response.status                         HTTP status code (200, 404, etc.)
  response.body                           Response body (string/JSON)
  response.headers                        Response headers
