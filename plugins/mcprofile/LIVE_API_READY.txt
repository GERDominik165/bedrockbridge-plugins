   New method: getProfileByGamertag(gamertag, retryCount = 0)
   Endpoint: /api/v1/bedrock/gamertag/{encodeURIComponent(gamertag)}

3. REAL HTTP REQUESTS
   Uses native fetch() API (if available in Bedrock)
   Fallback to Node.js http module
   Proper error handling and HTTP status checking

4. LIVE API CALL FLOW
   Player Joins
   → Get player.name (gamertag)
   → Call getProfileByGamertag(playerName)
   → Make HTTP GET to mcprofile.io
   → Parse JSON response
   → Cache for 1 hour
   → Display to admins (if admin tag present)
