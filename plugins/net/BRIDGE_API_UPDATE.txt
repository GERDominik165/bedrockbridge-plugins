HOW IT WORKS
================================================================================

DUAL REGISTRATION SYSTEM:

1. Chat Interface (!command)
   └─ world.beforeEvents.chatSend
      └─ CommandRegistry.executeCommand()

2. Bridge API Interface (if available)
   └─ bridge.commands.register()
      └─ CommandRegistry.handleBridgeCommand()

BOTH ROUTES:
   └─ Execute handler with context
      └─ Return result to caller

================================================================================
COMMAND REGISTRY API
================================================================================

Main Methods:

initializeBridge()
  - Detects and connects to Bridge API
  - Returns: boolean

registerCommand(name, handler, metadata)
  - Register single command
  - Returns: boolean

registerCommands(commandList)
  - Register multiple commands
  - Returns: boolean

executeCommand(name, args, context)
  - Execute registered command
  - Returns: { success, result, error }

getCommand(name)
  - Get command object
  - Returns: command or null

hasCommand(name)
  - Check if command exists
  - Returns: boolean

getAllCommands()
  - Get all commands
  - Returns: array

getCommandHelp(name)
  - Get help for command
  - Returns: help object

getAllCommandsHelp()
  - Get all command help
  - Returns: array

getStatus()
  - Get registry status
  - Returns: { totalCommands, bridgeConnected, commands[] }
