STEP 1: Deploy the Plugin
   → Copy imageframe.js to D:\BB\bridgePlugins\ImageFrame\
   → Reload server or plugin

STEP 2: Load an Image
   → Use command: /imageframe
   → Select: "🌐 Bild laden" (Load Image)
   → Enter: URL, width (1-10), height (1-10), glowing (Y/N)
   → Result: ✅ Image loaded and cached

STEP 3: Select Frames
   → Use command: /imageframe
   → Select: "📍 Item Frames"
   → Select: "✅ Aktivieren" (Enable)
   → Right-click item frames in world
   → Result: ✅ Frame counter shows selected count

STEP 4: Apply Image
   → Use command: /imageframe
   → Select: "📍 Item Frames"
   → Select: "🎨 Anwenden" (Apply)
   → Choose: Which image to apply
   → Result: ✅ Image applied to all selected frames!
