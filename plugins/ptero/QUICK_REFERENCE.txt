TROUBLESHOOTING:

Problem: Command not recognized
Solution: Make sure you're using /pterodactyl (not /bedrock or /bridge)
          Restart the server if it still doesn't work

Problem: Connection failed
Solution: Run /pterodactyl test
          Check API_KEY in pterodactyl-bridge.js (line 40)
          Check PANEL_URL in pterodactyl-bridge.js (line 39)
          Verify firewall allows outbound HTTPS

Problem: Menu doesn't open
Solution: Run /pterodactyl gui again
          Check server console for errors
          Run /pterodactyl debug for more info

Problem: No servers shown
Solution: Check your Pterodactyl Panel has servers
          Run /pterodactyl test to verify connection
          Check console logs for errors
