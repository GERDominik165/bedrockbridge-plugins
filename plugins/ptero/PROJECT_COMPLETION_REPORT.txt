DEPLOYMENT INSTRUCTIONS
================================================================================

INSTALLATION (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Copy pterodactyl.bedrock.plugin.js to:
   D:/BB/Bedrock-Bridge/scripts/bridgePlugins/

2. Start Bedrock server (auto-loads plugin)

3. In game, execute:
   /pman gui

4. Configure:
   - Enter Panel URL (https://your-panel.com)
   - Enter API Key (from Panel → Account → API Credentials)
   - Click "Test Connection"

5. Done! Start managing your servers from in-game!
