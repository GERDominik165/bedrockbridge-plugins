INSTALLATION (3 MINUTES):

STEP 1: Copy File
────────────────
Location: D:\BB\bridgePlugins\ptero\pterodactyl-bridge-bbcmd.js
Copy To: Your Minecraft Server\bridge-plugins\

STEP 2: Rename File (IMPORTANT!)
─────────────────────────────────
FROM: pterodactyl-bridge-bbcmd.js
TO:   pterodactyl.js

Windows Command:
  cd "Your Minecraft Server\bridge-plugins"
  ren pterodactyl-bridge-bbcmd.js pterodactyl.js

STEP 3: Restart Server
──────────────────────
Stop and restart your Minecraft Bedrock Dedicated Server

STEP 4: Test
────────────
Type in console or command block:
  bedrockbridge pterodactyl help

If you see the help text, it works!

TROUBLESHOOTING:

Problem: Command not recognized
Solution: Make sure command is: bedrockbridge pterodactyl <cmd>
          NOT: /bedrockbridge or /pterodactyl

Problem: Connection failed
Solution: Run: bedrockbridge pterodactyl test
          Check PANEL_URL and API_KEY in config
          Verify firewall allows HTTPS

Problem: No servers showing
Solution: Verify Pterodactyl panel has servers
          Run: bedrockbridge pterodactyl test
          Check server logs for errors

Problem: Slow response
Solution: Check rate limit (240 req/min default)
          Enable caching (default: on)
          Monitor command frequency
